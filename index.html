🚀 GitHub Pages Deployment Guide

Step-by-step instructions to publish a website

Step 1: Create a New Repository

  1. Log in to your GitHub account.
  2. Go to Repositories → New Repository.
  3. Enter your Repository Name.
  4. Select Visibility: Public.
  5. Click Create Repository.

Step 2: Upload Website Files

  1. Open your newly created repository.
  2. Click Add file → Upload files.
  3. Upload your index.html file.
  4. Click Commit changes.

Step 3: Configure GitHub Pages

  1. Go to Settings → Pages.
  2. Find the Build and deployment section.
  3. Set the Source to GitHub Actions.
  4. Select the Static HTML workflow.
  5. Review the workflow configuration.
  6. Click Commit changes if prompted.

Step 4: Check Deployment Status

  1. Open the repository's Actions tab.
  2. Select the Static HTML deployment workflow.
  3. Check the workflow execution status.
  4. A green check mark (✅) indicates that the workflow completed successfully.

Step 5: Open Your Live Website

  1. Go to Settings → Pages.
  2. Wait for the deployment to finish.
  3. Click Visit site to open your website.
  4. Test your website in the browser.
💡 Important Notes:
  • Keep index.html in the repository's root directory.
  • Deployment may take a few minutes.
  • Make sure the workflow completes without errors.
  • For a simple static website, HTML, CSS and JavaScript files can be used.

🎉 Website Successfully Published!

Your website URL will generally follow this format:

https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
